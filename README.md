# Tales of Eternia Remastered - Playable Cress Albane MOD
WARNING: Save files modified by this mod cannot currently be reverted to use Chat(the playable character). Back up your save files before installation.
## Overview

This mod replaces Chat's character slot with Cress Albane from Tales of Phantasia, adding Cress's artes, character graphics, and voice lines.

After installing the mod, open the regular in-game menu.

- **If Chat is already in your party:** Chat's slot will be replaced with Cress without changing their position in the active party or reserve party.
- **If Chat is not in your party:** Cress will be added to the next available slot at the end of your current party roster. For example, if you have four characters, Cress will become the fifth member; if you have five, he will become the sixth.
- **If Cress is added to the reserve party:** Use the normal party rearrangement function to move him into the active battle party.

### Additional Notes

- Cress's initial level, stats, stat growth, and equipment are based on Reid, as in the current implementation. This version does not inherit Chat's previous character development or equipment.
- Save files that already contain Cress will continue to work without reinitializing him.
- If your party temporarily consists of only one or two characters, the mod will postpone adding Cress. This is because adding him has only been verified from the fourth party slot onward.
- If all six party slots are occupied and Chat is not present, the mod will not overwrite another party member to add Cress.
- The AI behavior may still need further adjustments.

**Testing has only been performed with the early-game party consisting of Reid, Farah, and Meredy. The mod has not been tested throughout the entire story.**

## Important Warnings

- **Only install this mod if you accept that Chat(the playable character) will no longer be playable.**
- Save files created after installing this mod have not been verified to properly restore Cress back to Chat simply by removing the mod. Doing so will likely cause bugs.
- **There is currently no function to revert Cress back to Chat. Keep the mod installed when playing save files that have progressed with Cress.**
- The mod includes logic intended to prevent duplicate party members or unintended overwriting during Chat's story-related recruitment event. However, this behavior has not yet been verified by actually playing through that event.

## How to Activate Mystic Artes

- **Meikuu Zanshouken:** When your HP is in the red, press Attack + Artes + Guard simultaneously (same activation method as Reid's Aurora Wall).
- **Hiou Zetsuenshou:** Cancel Houou Tenku into itself (same method as Reid).
- **Eternal Blade:** Cancel Mouko Rengekiha into itself (same activation method as Reid's Ryuuko Metsugazan).

### Notes

- Additional requirements, such as arte usage counts, have been removed.
- **Eternal Blade's damage has not yet been balanced. Please use it with caution.**

## Installation

1. Close the game and extract all files from the ZIP archive. **Do not run files directly from inside the ZIP.**
2. Double-click `Apply.cmd` in the extracted folder.
3. The installer will attempt to locate the game using Steam's registry information. If the game cannot be found, manually select the folder containing the game's executable (`.exe`) file.
4. Once the installation is complete, launch the game normally through Steam.

### Additional Notes

- You can extract the files anywhere, including your desktop. They do not need to be placed inside the game folder.
- You can also drag and drop the game folder onto `Apply.cmd` to specify its location.
- If you encounter an "Access Denied" error, right-click `Apply.cmd` and select **Run as administrator**.
- Installation will be aborted if an unsupported game version or an incompatible version of an existing mod is detected.
- If you are using an older version of this mod, run `Restore.cmd` from that version first to remove its mod files before installing the latest version.

## Uninstallation (Important)

- Close the game and run `Restore.cmd` from the extracted mod folder. **This only removes the mod files.**
- If you want to play as Chat again, remove the mod files and load a save file created **before installing this mod**. Progress made after installing the mod cannot be carried over to that original save.
- **Please note once again: there is currently no way to directly revert Cress back to Chat in save files that have been modified by this mod.**

## Other Notes

- **Keep the extracted mod folder even after installation.**
- Files and folders such as `backup`, `rollback.json`, and `SaveBackup` are created during installation for backup and recovery purposes. Do not delete or redistribute them.
- Do not move `Apply.cmd` by itself. Keep all files together in the original extracted folder.
- As a precaution, **create a separate backup save before installing the mod**.
- Compatibility with other mods is not guaranteed.
- Future game updates may cause this mod to stop working.
- This mod has not been tested throughout the entire story or in every special battle.
- The included `licenses` folder contains license information for components used by this mod. Please keep this folder intact.
